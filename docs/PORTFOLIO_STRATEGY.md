# Estrategia de Portfolio GitHub (Fullstack Senior)

## Objetivo da Vitrine

Demonstrar capacidade real de entrega de software, nao apenas listar tecnologias.

## Principios de Alta Qualidade

1. Clareza: cada projeto deve explicar problema, solucao, stack e resultado.
2. Execucao: tudo precisa rodar localmente com instrucoes simples.
3. Documentacao: README completo com contexto tecnico e exemplos de uso.
4. Curadoria: poucos projetos fortes superam muitos projetos fracos.

## Checklist por Repositorio

- Titulo claro e profissional
- Descricao objetiva do problema
- Como rodar localmente
- Endpoints (quando API)
- Tecnologias e decisoes arquiteturais
- Testes ou smoke checks
- Proximos passos

## Recomendações para Perfil GitHub

- README do perfil com proposta de valor em 4-6 linhas
- 4 a 6 repositórios pinados com boa documentação
- Link para currículo e LinkedIn
- Um projeto front-end visualmente forte (portfólio ou dashboard)
- Um projeto API robusto em cada linguagem principal

## Roteiro de Publicacao

1. Revisar README raiz e docs
2. Validar projetos localmente
3. Commit inicial com estrutura
4. Publicar no GitHub
5. Pinar repositórios de maior impacto
6. Atualizar LinkedIn com links diretos
